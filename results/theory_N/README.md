# Capacity-matched RHSO stage-count sweeps

Configs `configs/experiments_theory_N_fixedB_final100.yaml` (B = N x M = 160, N in 1..32) and
`configs/experiments_theory_N_fixedM_final100.yaml` (M = 40, N in 1..16), generated by
`scripts/make_theory_N_configs.py`.  Two capacity-matched pairs: pMF-L/16 (410 M) vs JiT-L/16
(459 M) in pixel space, iMF-XL/2 (610 M) vs SiT-XL/2 (675 M) in latent space.  RHSO only, direct
terminal planning for both families, t0 = 1, beta = 1, 100 frozen ImageNet-100 images, seed 42.

lr and mu per task are the frozen-100 benchmark winners (`docs/best_hyperparameters.md`), not the
manuscript's values, and are frozen across N and across model size (SiT and iMF-B values reused
for SiT-XL/2 and iMF-XL/2).

* `theory_<protocol>_<model>/results.csv`, `results_per_image.csv` -- copies of `outputs/` after `--aggregate`
* `tables.md` -- five-task means per N, MeanFlow-minus-FM paired per-image tests, per-task tables
* `theory_N_sweep.pdf` / `.png` -- five-task mean PSNR and LPIPS against N (`scripts/make_theory_N_tables.py`)

Runs used one A100-80GB per model with up to three shard processes sharing the GPU, so the
`runtime_per_image` column is contended and not reported.
